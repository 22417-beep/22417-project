# 22417 - Галерия за Часовници

Този проект представлява модерна, минималистична уеб галерия за часовници. В нея потребителите могат да преглеждат наличните модели, да ги отварят в детайлен преглед, както и да добавят/премахват картички с часовници с glassmorphic ефекти и анимации.

Проектът е структуриран и контейнеризиран на три отделни услуги:
1. **Frontend (Nginx)** – обслужва статичните файлове и проксира API заявките към бекенда на порт `3000`.
2. **Backend (Node.js/Express)** – обслужва REST API на порт `5000`.
3. **Database (MongoDB)** – съхранява данните устойчиво.

## Как работят компонентите и връзката между тях

- **Frontend:** Статичните ресурси се сервират от Nginx на порт `80` (контейнер) / `3000` (хост). Когато клиентът направи заявка към `/api/...`, Nginx я пренасочва вътрешно към `http://backend:5000/api/...`.
- **Backend:** Node.js Express сървърът се намира на порт `5000` и е изолиран от външния свят, като комуникира само с базата данни чрез `mongoose`.
- **Database:** MongoDB работи в собствен контейнер и поддържа връзка с бекенда. Данните се съхраняват в обем `mongo-data`, гарантиращ устойчивост при рестартиране.

## Изграждане и стартиране

1. Уверете се, че имате стартиран **Docker Desktop**.
2. В терминала в основната папка изпълнете:
   ```bash
   docker compose up --build -d
   ```
3. Отворете приложението в браузъра: **http://localhost:3000**
